The full hardening toolchain, free and open.

The eBPF sensor, image builder, CLI, Helm chart, and GitHub Action are all open source. Everything you need to start hardening containers today, with no lock-in and no telemetry.

What's included

eBPF Sensor

CO-RE kprobe sensor written in pure Go using cilium/ebpf. Attaches to openat(), filters by cgroup/namespace, ships events over a ring buffer. Runs as a DaemonSet pod — no kernel module, no DKMS, no side-cars.

Go 1.26cilium/ebpfCO-REkernel 6.8+

Image Builder (hardener)

Takes the sensor manifest, resolves ELF shared-library dependencies recursively via readelf + ld.so.conf, applies language-runtime companion rules, then emits a new OCI image layer containing only the files that were actually observed.

go-containerregistryELF resolverCGO-free

CLI (tracepod)

Single static binary. Subcommands: profile, harden, push, sbom. CGO-disabled, cross-compiles to linux/amd64 and linux/arm64. Suitable for CI pipelines and developer laptops alike.

Static binarylinux/amd64linux/arm64

Helm Chart

Official Helm chart for Kubernetes deployment: DaemonSet for the sensor, aggregation controller deployment, RBAC (ClusterRole + ServiceAccount), ConfigMap-based role definitions. Tested on kind and AKS.

Helm 3DaemonSetRBAC

GitHub Action

Drop the tracepod/action step into any workflow. Profiles your workload in CI, hardens the image, pushes the hardened version alongside the original. Supports matrix builds across kernel versions.

GitHub ActionsKernel matrixOIDC push

Seccomp + AppArmor + SBOMs

Syscall allowlist (seccomp JSON) and AppArmor profile generated from the observed syscall set. CycloneDX and SPDX SBOMs produced by syft and signed with cosign. Both attestation formats pushed alongside the image.

seccompAppArmorCycloneDXSPDXcosign
Installation

Up and running in under five minutes.

Install via Helm, or download the static binary for the CLI. The sensor requires a kernel 6.8+ node with eBPF enabled (standard on any modern managed Kubernetes offering).

Full installation guide →
Install Tracepod

# Helm (recommended for Kubernetes)

$ helm repo add tracepod https://charts.tracepod.co.uk

$ helm repo update

$ helm install tracepod tracepod/tracepod \

    --namespace tracepod --create-namespace

 

# Or: download the CLI binary directly

$ curl -fsSL https://github.com/tracepod/tracepod/releases/latest/download/tracepod_linux_amd64.tar.gz \

    | tar xz -C /usr/local/bin tracepod

 

# Verify

$ tracepod version

  tracepod v0.1.8 linux/amd64
