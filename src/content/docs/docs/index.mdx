## What is Tracepod?

Tracepod is an eBPF-based container hardening tool. It attaches a CO-RE sensor to your running workloads, captures every file they open at runtime, and uses that observation to produce:

- **Minimised OCI images** — only files actually observed at runtime, plus recursively resolved ELF dependencies
- **Seccomp allowlists** — syscall profiles derived from observed behaviour, not guesswork
- **AppArmor profiles** — precise MAC policy generated from runtime data
- **CycloneDX + SPDX SBOMs** — signed with cosign and pushed alongside the image
